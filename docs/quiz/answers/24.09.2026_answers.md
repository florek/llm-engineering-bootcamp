2. **C** — Kluczowym mechanizmem transformera jest attention — model ocenia, które fragmenty wejścia są najważniejsze dla aktualnie analizowanego fragmentu.
3. **D** — Copilot to współpraca: człowiek prowadzi pracę, a AI pomaga (kod, streszczenia, sugestie) — nie pełne zastąpienie.

6. **D** — Każde `chat.completions.create()` to nowe, niezależne żądanie; serwer nie przenosi pamięci między wywołaniami.
7. **A** — Emergent intelligence to zdolności pojawiające się wraz ze skalą — model nadal przewiduje tokeny, ale przy dużej skali imituje bogatsze zachowania.
8. **C** — Prompt engineering pyta „jak napisać polecenie?”; context engineering — „jak dostarczyć wszystkie potrzebne informacje?” (dane, dokumenty, API, historia).
9. **B** — Tools to funkcje/API (wyszukiwarka, baza, pogodowe API, rezerwacje itd.), które model może wywołać, a wynik wraca do kontekstu.

13. **C** — Chat Completions: podajesz rozmowę (messages) i prosisz o uzupełnienie — kolejną wiadomość asystenta (nadal predykcja tokenów w formacie czatu).
14. **D** — `encoding_for_model` dobiera encoding/tokenizer właściwy dla danego modelu — różne modele mogą dzielić ten sam tekst inaczej.
15. **C** — Autonomia to technicznie: model wskazuje następny krok (np. „wykonaj X”), system to robi, wynik wraca do modelu — nie „własna wola”.

20. **C** — Obcięcie `text[:LIMIT]` od początku zachowuje start dokumentu, a końcówka długiego artykułu znika z wejścia modelu.
